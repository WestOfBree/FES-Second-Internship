# Summarist

An internal internship project completed during my time with FES Institute.

The goal was to follow a provided mockup and build a live, functional website based on that design. Assets such as logos, landing page visuals, and APIs were provided, and I implemented the rest of the platform using clean, component-based structure.

---

## Project Overview

This project was built with Next.js and follows clean coding practices, including reusable UI/UX components and separate styling files per page to keep the code easy to read and maintain.

The platform allows users to:

- create an account or log in as a guest
- browse a library of book summaries
- access premium content based on subscription status
- functioning audio player to listen to book summaries
- choose a subscription and continue to Stripe checkout (test mode)*

*Stripe is currently configured in test mode to prevent accidental purchases.
